# 可迁移发行与发布

从实际调用链清点服务：Hermes/OpenClaw 是用户本机 Agent，DeepSeek 是直连云对话/翻译，智谱是云识别，Whisper 是本机模型，GPT-SoVITS 是另一个训练/推理环境，Edge 是联网通用音色。别因“加一个后端”就新增无必要的服务/端口，别把开发机默认连接显示成全体用户可用。

统一设置和首次引导应允许基础陪伴先启动；Key/模型缺失不挡透明窗口。提供普通设置和高级端口/路径，右键与托盘均可再打开。配置完整验证后原子保存，合并已有值；标明即时生效与需重启项。取消首次引导下次仍出现，完成标记才持久保存。已有运行偏好/语言不应被默认配置覆盖。

Windows EXE 经验：

- QtWebEngine 有子进程、locale、resources、插件和动态库，便携文件夹比只交一个 EXE 更易验收。明确用户保留整个目录。
- 分清 EXE 旁的可写配置/状态与 `_MEIPASS` 中的只读资源。图标、加载插画、WebGL HTML/JS/WASM、语音索引等必须从冻结资源读取，不能依赖源码工作目录。
- `sys.executable` 冻结后是应用 EXE，不能继续 `-m src.core.stt_worker`。未来提供专门工作入口，避开 Qt/应用主循环；Windows 无控制台入口要处理标准流并实际验证原生模型初始化。Hsin 的源码隔离识别进程可用，但 v1.1.0 按用户要求暂缓 Whisper 冻结打包；工作入口能响应错误不代表真实模型可用，不能发布为已支持离线识别。
- 引用外部 Python/GPU 环境时注意冻结进程的 DLL 搜索/环境污染；隔离并恢复启动上下文，不修改用户全局 PATH。
- 检查模块名与安装发行名的差别。Hsin 使用 `webrtcvad-wheels`，模块仍叫 `webrtcvad`；默认 PyInstaller hook 若查找不存在的 `webrtcvad` 元数据，应提供本项目 hook 读取正确发行名，而不是盲目再安装另一个包。
- 无控制台 EXE 应在常规日志初始化前捕获启动异常，保存可定位的日志。构建成功后还必须运行 EXE；错误窗口或进程退出不能当作“端口正在加载”。
- 检查构建环境 PATH 带入的同名动态库。Hsin 曾误打入 Poppler 的 `icuuc.dll`，Qt 6 要的是 Windows 系统 ICU，导致 QtCore 导入报“找不到指定的程序”；确认导出不兼容后从资源表排除污染库，重新运行原生窗口。别在没有定位原因时不断叠加依赖。
- 使用显式文件清单。Key、本机绝对路径配置、Whisper ASR 权重、训练权重、受限 PMX/动作、私人聊天缓存和运行日志默认不分发，按用户明确要求选资源。识别组件和 VAD 小模型不等于 Whisper ASR 权重，说明清楚。
- 预存语音先验证可在缺少训练配置的安装中播放；任意新文字仍需配置服务/备用引擎，界面和发布说明不能宣称所有语音离线可用。
- 可发布训练/推理参数和参考请求模板，将开发机路径替换为明确占位符，并注明模板不含权重、预处理产物及上游基础模型。指向上游官方安装文档，保留版本、硬件要求和致谢；不能让用户误以为复制配置即可生成任意语音。

打包后从无个人配置的路径启动 EXE，验证引导、缺资源提示、真正的 WebGL/PMX 导入、实际 PCM/口型和 worker 管道；源代码的成功启动不等于 EXE 成功。扫最终 ZIP/目录与冻结模块，确认排除目标、保留依赖许可和对应源码/构建入口。

用户授权正式发布后，为新的最终内容写版本说明和后续计划，保留已有发布标签，不移动旧正式版。提交前确认 secret/私有资源清单；使用明确的版本 tag、资产 SHA256 和对应源提交。上传完整便携 ZIP、校验文件与 Skill 包后检查 GitHub 上实际资产/版本状态，不能以本地打包完成代替发布成功。

Hsin 对应文件可作为代码定位：`src/core/tts_manager.py`、`speech_stream.py`、`chat_manager.py`、`sprite_window.py`、`src/ui/reply_bubble.py`、`settings_dialog.py`、`src/assets/pmx_viewer/animation_runtime.js`、`pose_transitions.js`、`pose_cloth.js`、`packaging/Hsin.spec`。迁移 Aemeath 时只摘与它的管线匹配的逻辑，不复制 Hsin 的角色路径、凭据、端口或具体骨骼常量。
