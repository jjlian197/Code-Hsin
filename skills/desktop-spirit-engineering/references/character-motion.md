# 角色动作与取景

## 渲染材质与加载

Hsin 使用原始 PMX、MMDAnimationHelper 与 Ammo/Bullet，不必转 GLB。保留 toon、sphere、透明贴图和原生 morph。发现角色半透明时先区分窗口 alpha、材质 opacity、alphaTest/transparent 与贴图 alpha，检查脸/身体实际材质，不要把所有透明材质统一改成不透明。加载完成应等贴图可用且实际绘制后，再撤加载插画；竖屏/横屏图片只按布局选择、等比例完整展示，失败有可见状态。

## 姿态绑定与手势

- 原模型 T-pose 不等于角色待机。手臂下垂应是一层持续的基础姿态，手势通常叠加上半身和手指。
- 同一帧停旧 action 后才启用新 action，可能短暂恢复绑定姿态。先接上新的待机绑定，再停止旧动作；mixer finished 回调先记录，等 mixer 当前遍历结束后切换。
- 退出全身躺姿需还原完整骨骼状态与动画绑定缓存，而非只播放上半身 idle。检查 root、骨骼平移、scale、IK/Grant、masked idle 与旧 clip/action。
- 中断比心/X 手势可保留当前局部增量后短暂淡出。Hsin 使用约 0.3 秒；角色不同需按视觉检查调整。重复触发同一手势不应从头重置。
- 掌心朝向需要模型实际食指/中指/小指建立掌面法线，不能只猜手腕欧拉角。比心必须按骨长与指尖接触重新校准；交叉手需错开前后深度、留意袖口。

原生 PMX 的旋转还受 Grant 和模型初始轴影响。先看肩、前臂、手腕、手指的世界坐标，再决定重定向；GLB 的 bind pose/骨轴不能默认与 PMX 一致。已有 `mmd-glb-gesture-calibration` Skill 可用于相应手势任务，但先检查目标管线是否匹配。

## 站立与侧躺

AMC 是运动通道，必须结合对应 ASF 的骨轴、旋转顺序、单位和帧率解析。选到“躺下/起身”动作只是起点；要按目标 PMX 骨长、Grant、身体参考和具体落点对齐。

Hsin 的经验：独立躺下和起身片段均匹配目标待机/撑头侧躺；躺下开头颈部扣掉原站立参考偏转；起身尾部明确回到完整下垂站姿。进入片段可由当前姿态混合首段，而不是先还原 T-pose。固定世界地面、脚点和身体支撑，保留模型比例，不能用不断重新 fitBounds 来掩盖错误 root motion。

`standing → lie_down → side_lying → get_up → standing` 应由状态机管理。途中请求起身先完成当前安全支撑段；手势等起身后执行，最终有效请求有明确规则。不要随意倒播 mocap 或立即瞬移，尤其角色头发/衣摆有状态时。

## 布料与镜头

站立原生 Ammo 不一定适合大幅贴地动作。Hsin 的过渡/侧躺使用独立骨骼 PBD，根随身体，重力、阻尼、骨长/邻接约束、身体胶囊与地面约束；进入渐入，站稳前渐出，随后恢复用户原物理偏好。这不是逐三角形自碰撞，不能承诺精细褶皱或衣物层间无穿模。

动作期间用覆盖整条路径的稳定取景。头部模式保留耳朵、手势、撑头手臂等用户关心的轮廓，适度加宽画布；侧躺另用上半身取景。过渡临时全身，躺稳/站稳后平滑进入所选近景。身体 ground frame 与窗口 floor anchor 一起处理，防止横竖尺寸切换像在漂移。

触摸使用实际蒙皮 raycast 和当前骨骼，不用站立时固定屏幕矩形套侧躺。手挡胸前优先识别手；发辫不应当尾巴。空白、冷却期和关闭触摸的行为要明确。点击与拖动分开；眼神鼠标跟随不等于用户互动。

## 最小验证

检查首帧、接触点、尾帧及一次中途切换；记录真实世界身体坐标、手臂角度、掌面方向与 fully_visible。有两种形态或不同物理模式时选择能覆盖其差异的检查。帧计时可固定用于回归，但最终以原生渲染和实际点击确认，不用骨架数值替代视觉判断。
