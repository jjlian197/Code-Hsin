## 已知问题与修复验收

### VOS-FACE-001：眨眼时睫毛不跟随眼睑

- **状态：Build 6 已修复并完成开发侧验证，AVP 验收待完成。** 报告日期：2026-10-07。
- 根因：原 PMX 的眨眼形变包含睫毛，转换后仍有其顶点偏移；但 RealityKit 对同一骨架分开的面部网格只实际驱动首个形变网格，睫毛因此停在睁眼位置。原生模拟器已复现该表现。
- 修复：将眼睑、睫毛、眼白和口腔内具有面部形变的网格合并，重映射稀疏顶点索引，使用材质子集保留贴图；只修改生成副本。心一／二阶段均重新导出，爱弥斯私有副本也合并剩余口腔／眼白。Hsin 使用原始闭眼幅度，爱弥斯保留参考闭眼补偿。
- 证据：原生模拟器已观察心一阶段半闭／全闭、心二阶段全闭及爱弥斯全闭，睫毛随眼睑移动；网格测试覆盖形变、蒙皮、材质和重复转换。不能据此替代 AVP 外观验收。
- 验收：心一／二阶段及爱弥斯分别观察睁眼、半闭、全闭和重新睁眼；睫毛与眼睑同步，无悬空、穿插或回到睁眼后残留形变。必须核对原生渲染与 AVP 实际外观。

### VOS-FACE-002：嘴形不自然，缺少多种口型

- **状态：Build 6 多口型实现与中日原生播放验证已完成，自然度及 AVP 验收待完成。** 报告日期：2026-10-07。
- 原限制：仅按播放器平均音量驱动 `a`，其他口型置零；口腔内部的独立网格亦受上述导入问题影响。
- 修复：解码 WAV PCM，以 20 ms RMS 能量门控保留停顿；中文拼音／日文拉丁转写提供 `a/i/u/e/o` 近似提示，按实际播放器时钟采样，以不同开合时间常数平滑混合。停止、重置、播放结束清除权重；异步准备完成后重新核对回合，避免旧音频回流。非支持 WAV 格式保留音量驱动回退。
- 限制：文本提示均匀分配到有声帧，属于近似口型，尚非逐音素强制对齐。
- 证据：Swift 检查覆盖五口型、静音、边界、异常 WAV 与平滑归零，并使用真实中日 TTS WAV；原生静音播放探针使用实际 AVAudioPlayer 时钟，中文样本产生 `a/e/i/u`，日语五种口型均产生非零驱动，结束后清除。真人麦克风未自动开启。
- 验收：使用真实中文和日语 TTS，检查多种口型变化、音频同步、过渡自然、静音闭嘴，以及停止／打断／角色切换后没有残留；心两种形态与爱弥斯分别验收。

### VOS-POSE-001：侧躺、站立与过渡

- **状态：Build 7 实现、双形态状态链路检查与构建通过；部分原生外观待 Mac 解锁复验，AVP 未安装。**
- 资源：复用 macOS 的双形态校准文件，校验 PMX SHA-256；独立 `lie_down` 7 秒、`get_up` 7.7 秒，以及撑头 `side_lying` 定格。起身不是倒放躺下。
- 转换：30 fps 采样完整骨架并求值 PMX Grant 辅助骨；复用桌面 PoseCloth 离线采样衣发，统一全部骨骼衔接端点。待机与手势也恢复完整根节点、腿部及辅助骨，避免残留侧躺姿态。
- 运行：`standing → lyingDown → sideLying → gettingUp → standing`；以实际完成事件／控制器完成状态推进。途中反向请求先完成当前支撑段，再执行最新目的地；手势先排队起身，用户新的姿态请求覆盖旧手势。角色／形态切换清空队列并使旧加载、控制器失效。
- 空间：同一次加载仅按整条路径包围盒适配一次，模型空间地面、位置及尺寸在过渡中保持固定，不按每帧重新取景。
- 已验证：双形态全套骨骼端点一致、有效数据与身体逐帧旋转连续；状态机覆盖重复请求、途中反向、最新目的地与 50 次往返。一阶段躺下中段、撑头侧躺与起身中段已观察到原生渲染。双形态实际回执均为 `lie_down → side_lying → get_up → idle`；一阶段途中反向为 `lie_down → get_up → idle`，排队手势为 `lie_down → get_up → wave → idle`，均未提前重置支撑段。
- 外观待办：Mac 检查期间锁定，二阶段姿态及双形态完成站立的画面尚未取得。实际状态／控制器完成不代替这些外观验收。
- 限制：侧躺持有稳定定格；离线衣发没有实时碰撞反馈，也未迁移桌面逐顶点地面投影。真实空间接触、细节穿模、头发／衣摆与 AVP 全流程仍待验收。爱弥斯暂不开放未经其骨架校准的姿态。

## 平台适配

- macOS 的托盘／右键菜单改为空间工具栏与设置面板；拖动、大小与近景改用系统窗口操作和空间控制。
- 桌面穿透、置顶、Spaces、鼠标屏幕边缘行为没有直接等价的头显行为，不照搬 Qt 窗口策略。
- Three.js／Ammo 的 MMD、Grant、IK、toon 和布料实现无法直接作为 RealityKit 动画运行。先建立匹配 Hsin 骨轴的可重复转换与动作采样，再评估实时物理；不能将爱弥斯专用网格修正套到 Hsin。
- 后端随角色切换：Hsin 使用 PC 上已有 Hermes Agent 的 `default` profile，通过现有 HTTPS 桥接访问；本机保存的 DeepSeek 选择是先前测试配置，不能作为角色默认后端依据；爱弥斯沿用参考 visionOS 的 OpenClaw `agent:main:main`。Hsin 继承其 macOS 角色配置，禁止将爱弥斯的 Agent 会话作为全局默认。角色各自保存后端选择，取消旧任务并分离直连历史；不修改用户 OpenClaw 全局配置。
- 资源仍私有，令牌保存在 Keychain，Mac／PC 保留推理与密钥。新安装及更新默认关闭麦克风。
