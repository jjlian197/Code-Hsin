# 发行配置与后端规划

更新：2026-10-03。v1.1.0 已接入统一设置、首次启动引导、Windows EXE、预存中日语音和 GPT-SoVITS 配置模板；可选托管网关等仍是计划，不代表已经部署云服务。

## 功能依赖

| 功能 | 当前执行位置 / 是否联网 | 用户需要准备什么 |
| --- | --- | --- |
| PMX、表情、动作、衣发物理、大头/侧躺、加载插画 | 本机，运行时离线 | PMX 与贴图；侧躺 FBX、匹配模型的过渡校准文件；无 Key |
| 透明窗口、拖动、托盘、气泡、视线跟随 | 本机，离线 | 普通外观设置；无 Key |
| 番茄钟、情绪、好感度、状态保存 | 本机，离线 | 无服务配置，不需要账号或云端数据库 |
| DeepSeek 直连聊天 | DeepSeek 云端 | DeepSeek API Key；模型名；无需填写本地端口 |
| Hermes 聊天（当前默认） | 连接本机 Hermes；模型是否联网由 Hermes 配置决定 | 安装/启动 Hermes、配置心的 Agent；模型凭据在 Hermes 中设置；地址和会话凭据通常自动发现 |
| OpenClaw | 仅保留本地接口，实际联调暂缓 | 若以后启用，需要网关、Agent、凭据；上游模型依赖由 OpenClaw 决定 |
| 心的中日 GPT-SoVITS 合成 | 本机，资源齐备后离线 | 推理环境、中日权重、参考原声/文字、基础模型及音色配置；当前推理代码固定 CUDA / 半精度，不能宣称普通 CPU 机器已支持 |
| 中日固定触摸/试听回应 | EXE 内预存 WAV，本机离线 | 开启语音并选择心的音色；无需 Key 或推理环境；任意新句仍需上一行的完整环境 |
| Edge 通用中日语音 | 微软在线服务 | 联网；当前 edge-tts 不要求用户 API Key；通用音色不是心的训练音色 |
| 跨语言自动翻译 | DeepSeek 云端；命中本地缓存可复用 | 同一份 DeepSeek Key，当前不随 Hermes 后端切换 |
| 麦克风采集、VAD、热词提示、防回声 | 本机 | 麦克风权限、输入设备；无 Key |
| Whisper 中日识别 | 本机 CPU int8，识别时离线 | 识别依赖和已下载的模型；首次准备模型需要下载或手动导入；无 Key、无监听端口 |
| 智谱 GLM-ASR 识别 | 云端，发送短句 WAV 与热词 | 智谱 API Key；无需本地端口 |

v1.1.0 EXE 按用户要求暂缓 Whisper 运行组件打包，上表 Whisper 行适用于源码版；EXE 保留云识别与麦克风采集，不把缺陷识别入口作为可用功能发行。
| 原声/缓存播放、音量口型、分句排队 | 本机 | 本地音频；生成这些音频的服务依赖另计 |
| HTTP / WebSocket 控制 | 本机回环地址 | 默认端口由程序使用；无需云服务或 Key |

云端调用会发送对应的聊天文字、待翻译文字、待合成文字或待识别音频。Hermes/OpenClaw 在本机运行不等于其上游模型离线。当前应用没有集成独立本地大语言模型；要完全离线聊天，需在 Agent 一侧配置可用的本地模型。

## Key 与连接凭据

| 配置 | 用途 | 是否必须 |
| --- | --- | --- |
| `chat.deepseek.api_key` / `DEEPSEEK_API_KEY` | DeepSeek 聊天及自动翻译，共用一份 | 只在启用这些云功能时需要 |
| `stt.zhipu.api_key` / `ZHIPU_API_KEY` | 智谱识别 | 可选；Whisper 无需它 |
| `chat.hermes.token` | 本地 Hermes 会话认证 | 通常从握手获得，手填仅作为备用；不是模型 API Key |
| `chat.openclaw.token` / `OPENCLAW_GATEWAY_TOKEN` | 本地 OpenClaw 网关认证 | 当前暂缓；不是模型 API Key |

因此，当前 Hsin 自己涉及的是 **两种云 API Key，加两种本地连接凭据**，不是每个功能都要一个 Key。Hermes/OpenClaw 的模型供应商 Key 属于各自配置，不应要求在 Hsin 再填一遍。环境变量优先于文件配置。

当前设置界面把手填密钥保存到被 Git 忽略的 `config.local.yaml`，这是本地明文配置，不是系统凭据库。发行版建议改用系统凭据库保存敏感值；界面与状态只展示“已配置/未配置”，导出诊断时排除密钥。

## 端口与资源配置

| 当前地址 / 配置 | 谁使用 | 发行时如何处理 |
| --- | --- | --- |
| `127.0.0.1:18765` | Hsin WebSocket 控制 | 保留默认；冲突时给出明确诊断，支持自动选择并登记实际端口；手动覆盖放高级设置 |
| `127.0.0.1:18766` | Hsin HTTP 控制、启动器探活与退出 | 同上；自动变更时同步启动器和外部客户端的发现机制，不能只改监听地址 |
| `127.0.0.1:19880` | 本地心音色推理 | 当前已按需启动；未来由应用分配/探测，普通用户只选语音包 |
| Hermes 动态端口 | 本地 Agent 服务 | 已从 `spawn-ledger.json` 自动发现；默认不要求手填 |
| `127.0.0.1:18789/ws` | 预留 OpenClaw 网关 | 暂缓，放高级设置 |
| DeepSeek、智谱、Edge | 外部 HTTPS/WSS 服务 | 固定服务入口，用户不填服务端口、不做路由器端口映射 |

当前 Hsin HTTP/WS 与语音端口仍是固定配置，尚未实现冲突后自动换端口；实际控制地址写入 `.runtime/endpoints.json`。Hermes/OpenClaw 当前校验只接受本机地址；语音合成也固定本机回环地址，远程/局域网后端并非填一个 URL 就能启用。

还需要处理 **资源导入**：模型/贴图、侧躺动作/校准、Whisper 模型、GPT-SoVITS 环境与语音包。它们不是 Key 问题，单做云代理不能解决。新用户不应训练音色或编辑机器绝对路径；在资源可分发的前提下提供成品包，否则提供本地导入与完整性检查。已有模型说明限制二次配布，资源来源和许可仍需按现有发布说明处理。

## 建议的后端分工

建议先统一现有本地服务管理与设置入口，再接可选云网关。无需为了配置界面立即增加多个独立服务。

- **桌面端**：模型、窗口、交互、麦克风采集/VAD、播放/口型、番茄钟和好感度保持本机运行。
- **本地后端层**：统一聊天、识别、合成、翻译的调用与取消；发现 Hermes，管理自己的语音/识别进程；返回功能就绪状态和缺失资源。现有 `ChatManager`、`TTSManager`、`STTManager` 已有基础，可渐进整理。先保留当前进程结构，不额外增加用户需要填写的端口。
- **可选 Hsin 云网关**：代理聊天、翻译与云识别。使用运营方凭据时，用户只登录 Hsin；服务端管理上游 Key、额度、限流与会话隔离，运营方承担调用成本。以后如提供心的云音色，再增加 GPU 推理、排队和中日模型调度，不作为第一阶段必需项。

若只做本地后端，仍然需要用户自带 DeepSeek/智谱 Key，或连接已经配置好的 Hermes。只有运营方提供受控的云服务，才能让普通用户不申请第三方 Key；不能把运营方 Key 内置到桌面发行包中。

Hermes 的电脑操作能力继续留在本机。云端返回回复并不自动授予它执行本地操作的能力；当前桌面控制接口不直接暴露到公网。长期陪伴状态暂不做云同步，避免无必要地增加账号依赖。

## 发行界面与默认体验

首次启动只展示三种选择：

1. **基础陪伴**：导入模型即可用外观、动作、触摸、番茄钟与好感度；语音和聊天未配置也能正常使用这些功能。
2. **连接已有 Hermes**：自动检查本机服务、选择心的 Agent；可选导入心音色和 Whisper。仍保留当前项目默认 Hermes 的偏好；缺少服务时引导连接，不假设每台机器都有本机现成的 Hsin。
3. **使用云服务**：云网关完成后提供 Hsin 登录；此前提供“自带 Key”，DeepSeek 必填、智谱识别可选。Edge 可作明确标注的联网通用音色。

基本设置只放连接方式、语言、音色和麦克风设备；端口、数据目录、模型名、手动会话凭据放高级设置。每项功能显示“可用/缺资源/缺凭据/服务未启动”，并提供对应导入或连接操作。

离线模式需关闭自动翻译、Edge 回退和云 ASR，使用本地音色与 Whisper；聊天还需要 Agent 配置本地模型。当前 `voice.fallback` 与 STT 自动选择可能使用云端，发行界面需要说明实际数据去向，不能把“首选本地”显示成“保证离线”。

## 下一步顺序与验收

1. 先做统一设置/首次启动引导、资源导入和功能就绪诊断。新机器不修改 YAML、不填内部端口即可启用基础陪伴；Hermes 缺失不阻塞桌面功能。
2. 管理内部端口与子进程，接入系统凭据库。验证冲突诊断/发现、服务重启、应用退出清理和敏感值不进入状态输出。
3. 增加可选云网关及客户端适配：流式聊天、翻译、ASR、登录/额度与取消。验证租户隔离、迟到结果丢弃、与现有分句朗读兼容；保留直连与 Hermes。
4. 在真实新 Windows 机器打包验收；再将同一后端协议用于 macOS/visionOS。云心音色、局域网推理与状态同步另行评估。

外部说明：[DeepSeek API 认证](https://api-docs.deepseek.com/api/deepseek-api/)、[edge-tts 项目](https://github.com/rany2/edge-tts)。智谱云接口与热词按项目当前实现记录，当前自动选择日语仍走本地 Whisper。
