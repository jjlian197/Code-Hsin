# 闲置释放与CPU听写补测

2026-10-05，接续[4080S共同负载测试](LOCAL_STACK_RESOURCE_TEST.md)，按用户要求实施ASR/GPT-SoVITS闲置释放，并比较Qwen3-ASR-0.6B的CPU模式。复用已有权重和同两段中日合成录音，不下载、不打开物理麦克风、不修改日常设备配置。

## 已实施的闲置释放

源码默认保温600秒；高级设置的`runtime.model_idle_seconds`可设0关闭，最大3600秒。聊天、识别、合成、预热、实际播放和待播队列全部结束后才计时；有新活动重新计时。后台识别/合成请求也受串行锁保护，不能因界面已经取消就提前终止。仅释放应用自己启动的Qwen ASR与GPT-SoVITS进程，不关闭用户已有外部服务，不删除音频缓存或模型文件。

下次请求自动重新加载；缓存播放不会把已卸载的TTS标为已预热。Ollama已有5分钟保温沿用，与语音模型及角色形态的闲置计时分别管理。

真实PMX窗口测试使用5秒加速阈值验证逻辑，未等待完整10分钟。GPU方案完成中日两轮后约6.3秒释放ASR/TTS；释放前项目净显存约9.57GiB，随后约4.54GiB，下降约5.03GiB，4B仍驻留。再输入中文成功重新启动两个模型进程并播放新合成音频。再次唤醒整轮59.38秒，含实际音频播放，不能把全部时间算作模型加载；冷启动等待确实明显。

## ASR单独对照

每种设备运行6次相同请求，中文首轮冷启动不纳入热请求统计；热中文2次、热日文3次，样本较小。CPU固定4线程、float32，GPU使用4080S、bf16。

| 项目 | 4080S ASR | CPU ASR |
| --- | --- | --- |
| 热中文中位数 | 0.67秒 | 2.40秒 |
| 热日文中位数 | 0.73秒 | 2.69秒 |
| ASR新增整卡显存采样峰值 | 约2.05GiB | 0 |
| ASR私有物理内存常态 | 约1.76GiB | 约3.66GiB |
| ASR私有物理内存采样峰值 | 约1.76GiB | 约4.20GiB |

两种设备的识别文字一致；日语原有“二文→二分”错误仍存在。CPU本轮初次请求10.45秒、GPU30.97秒，两次运行顺序与系统缓存不同，不能据此断言CPU冷启动普遍更快。实际设备字段与整卡采样确认CPU模式未使用CUDA。

## CPU听写的整套组合

PMX、4B和GPT-SoVITS继续绑定4080S，只有ASR使用CPU。6轮中日交替新合成，加闲置释放后1轮中文，共7轮实际PCM播放通过；窗口内215.03秒，无OOM或模型链路错误。ASR/TTS约5.97秒后释放，两个进程再次加载通过，唤醒整轮51.58秒（含12.60秒音频播放）。本轮日语请求得到中文回复，功能链路通过不代表日语回复质量通过，也不能拿不同回复长度的整轮耗时比较设备性能。

| 资源 | 活跃轮次中位数 | 全程采样峰值 |
| --- | --- | --- |
| 项目净显存估算 | 7.41GiB | 7.93GiB |
| 4080S整卡显存 | 7.78GiB | 8.30GiB |
| 本次进程RSS，含共享页 | 9.74GiB | 10.47GiB |
| 本次进程私有物理内存USS | 8.54GiB | 9.27GiB |

测试前背景372MiB，退出全部测试进程后回到372MiB；原始15秒清理采样含驱动短暂回收延迟，结束后额外核对显存与本轮ASR/TTS进程均已退出。闲置释放前净显存约7.41GiB、私有RAM约8.65GiB，释放后分别约4.53GiB和1.99GiB，此时4B仍驻留。

相比第一轮全GPU净显存峰值约9.9GiB，CPU听写组合约7.9GiB，但RAM更高。两轮负载长度和回复不同，整套差值仅作实际容量参考，单独ASR对照更适合比较速度。4080S建议继续GPU听写；CPU保留为低显存候选，尚未替换用户日常配置。净峰值已接近8GB且不含桌面背景，不能据此认定8GB设备可稳定同时常驻；还需4B部分CPU运行或主脑/TTS轮换等措施及真机验收。
