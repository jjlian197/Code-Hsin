# v1.0.0 正式版

发布：2026-10-03。首个 Windows 源码正式版。

## 本版功能

- 直接加载心的双形态 PMX；透明窗口、托盘、拖动、置顶、穿透恢复和可双击的启动/停止入口。
- 按竖向/横向画布展示用户提供的加载插画，等比例保留完整图片；加载结束自动收起，失败仍保留提示。
- 全身、正面和左右斜侧大头模式；侧躺大头关注头部、肩胸与撑头手臂，过渡临时全身，躺稳/站稳平滑恢复近景。
- 双手比心、胸前 X、分部位触摸、表情、眨眼、视线跟随、呼吸和对话/陪伴动作。
- 站立→侧躺→独立起身；修复躺下开头颈部扭曲与起身后双臂平举。过渡与侧躺使用骨骼衣发动态模拟，支持原物理开关和重置。
- 中日语音切换、GPT-SoVITS、分句朗读、音频口型；麦克风/VAD/STT 与“心、心月狐”等热词。
- 默认 Hermes Hsin Agent、DeepSeek 直连；OpenClaw 仅保留接口。
- 番茄钟、情绪与好感度、本地状态保存以及 HTTP/WebSocket 控制。

这是源码发布，不包含独立 EXE。下载本版本源码，按 [README](../README.md) 配置本地资源与依赖，然后双击 `启动心.vbs`。模型、FBX、原声、训练权重、密钥和本地校准产物不随源码分发；侧躺过渡的重建步骤见 [过渡说明](SIDE_LYING_TRANSITION_PLAN.md)。加载插画随项目提供并保留原图署名。
