# v1.1.0 正式版

发布：2026-10-03。Windows x64 EXE 便携版与源码。

- 新增可直接运行的 `Hsin.exe`，无需安装 Python；提供完整便携 ZIP、SHA256、第三方说明和配置模板。
- 内置 28 条中日固定回应、72 条精选原声与试听音频。预存语音独立于本机训练路径，不需要 GPU；新的心语音仍需用户部署 GPT-SoVITS 和权重。
- 统一设置和首次启动引导；后续从右键/托盘修改模型、端口、后端、语音与麦克风。Key、模型与服务均由用户按需配置。
- 修正分句朗读的回复长度和朗读范围，提供最近回复/选中内容重读；气泡跟随实际播放逐句展示，无语音时按固定速度推进。已配置的 GPT-SoVITS 音色启动时后台静音预热。
- 闲置 10 分钟自动侧躺，互动立即发起起身；需用户自行准备模型对应的动作/过渡资源。
- 公开中文、日文 v2ProPlus 训练与推理模板，添加 [GPT-SoVITS 致谢和部署指南](GPT_SOVITS_SETUP.md)。
- 开发经验整理为可安装的 `desktop-spirit-engineering` Skill，供后续优化 Aemeath spirit。

## 下载与配置

下载 `Code-Hsin-v1.1.0-windows-x64.zip`，解压整个 `Hsin` 文件夹，再双击 `Hsin.exe`。保留 `_internal`。首次引导中导入自行取得的 PMX 文件，贴图保持原目录结构。完整步骤见 [EXE 使用说明](WINDOWS_EXE.md)。

发行包不含 Whisper 运行组件与 ASR 模型、PMX/FBX、训练权重、私人聊天缓存或 API Key。按用户要求暂缓本地 Whisper 的冻结打包，保留源码接口；EXE 可配置智谱 Key 使用云识别。GPT-SoVITS 配置 ZIP 不含音色权重。

## 验证与后续计划

设置、分句/气泡、语音、桌面与发行路径的针对性检查通过，新增外部 GPT 环境隔离的回归检查。实际 Windows EXE 已验证首次引导、无私有配置启动、双形态 PMX 导入和中日预存音频解码播放；其他 Windows 设备的首次运行仍需反馈。

后续优先精修手势接触与布料碰撞、优化首句语音等待、单独解决 Whisper 运行组件打包并验收真人麦克风听写；继续安排 **macOS 与 visionOS**，对齐 Aemeath spirit 对应平台。OpenClaw 保持接口，生活助手维持番茄钟范围。详见 [ROADMAP](ROADMAP.md)。

# v1.0.0 正式版

发布：2026-10-03。首个 Windows 源码正式版。

## 本版功能

- 直接加载心的双形态 PMX；透明窗口、托盘、拖动、置顶、穿透恢复和可双击的启动/停止入口。
- 按竖向/横向画布展示用户提供的加载插画，等比例保留完整图片；加载结束自动收起，失败仍保留提示。
- 全身、正面和左右斜侧大头模式；侧躺大头关注头部、肩胸与撑头手臂，过渡临时全身，躺稳/站稳平滑恢复近景。
- 双手比心、胸前 X、分部位触摸、表情、眨眼、视线跟随、呼吸和对话/陪伴动作。
- 站立→侧躺→独立起身；修复躺下开头颈部扭曲与起身后双臂平举。过渡与侧躺使用骨骼衣发动态模拟，支持原物理开关和重置。
- 中日语音切换、GPT-SoVITS、分句朗读、音频口型；麦克风/VAD/STT 与“心、心月狐”等热词。
- 默认 Hermes Hsin Agent、DeepSeek 直连；OpenClaw 仅保留接口。
- 番茄钟、情绪与好感度、本地状态保存以及 HTTP/WebSocket 控制。

## 获取与启动

这是源码发布，不包含独立 EXE。下载本版本源码，按 [README](../README.md) 配置本地资源与依赖，然后双击 `启动心.vbs`。模型、FBX、原声、训练权重、密钥和本地校准产物不随源码分发；侧躺过渡的重建步骤见 [过渡说明](SIDE_LYING_TRANSITION_PLAN.md)。加载插画随项目提供并保留原图署名。

## 验证与限制

双 PMX 的颈部起点、持续下垂站姿、衣发接地与反复切换已通过实际 Windows Qt/WebGL 检查。侧躺近景通过三个视角、上半身轮廓、衣发运动、面部点击、全身切换和起身恢复检查；现有触摸交互已回归。两种加载插画、真实加载后收起与失败提示也已通过实际窗口检查。

布料是骨骼近似，逐三角形自碰撞、衣物层间碰撞、贴身褶皱和撑地手接触细节仍需改进。STT 的真实麦克风/云端听写、其他平台与独立 EXE 尚未完成验收。后续继续安排 macOS 与 visionOS，分别对应 Aemeath spirit 的平台体验；详见 [ROADMAP](ROADMAP.md)。
