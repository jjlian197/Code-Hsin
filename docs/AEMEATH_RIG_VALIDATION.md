## 本轮修正

爱弥斯实际躯干层级为 `上半身 → 上半身2 → 上半身1 → 首`。骨名编号不等于躯干高度；近景改为选择颈部祖先链上最近的已映射躯干，避免机械选择“上半身2”导致镜头偏低、偏远。Hsin 两种形态仍选择原来的“上半身2”，回归检查通过。

相同骨名不表示复杂手势已经适配。运行时仅为已校准的 Hsin 双形态开放原有复杂手势，爱弥斯暂时提供 idle/nod 与行为层视线跟随；不直接迁入 GLB 的局部四元数，也不把心的比心/X/躺姿校准当作爱弥斯参数。

## 复现与产物

```powershell
$samplePmx = "D:/Workspace/aemeath-spirit/src/assets/models/vrm/鸣潮_爱弥斯(绑骨修模后)_by_鸣潮_230143b4780d2dd4d00b41a07dd1c180/鸣潮_爱弥斯1.05.pmx"

```

工具打开隔离的 Qt/WebGL 窗口，沿用源 PMX 目录的贴图，生成骨架映射、运行状态、实际语义骨世界坐标与截图。不开麦，不启聊天、语音或控制服务。默认不传 --model 时仍检查心双形态，--physics 才增加原生物理检查；当前检查阈值针对项目的 MMD 基础角度模板，不代表任意模型必须无需校准就通过。

产物仅保存在本机忽略目录 `.runtime/rig-aemeath/`：`sample/rig_map.json`、`sample/report.json`、`sample/preview.html`、`validation.json`，以及待机、点头、转头、复位、三个近景和物理状态截图。数值检查结果 success 为 true；映射分析文件中的 runtimeValidated 保持 false，实际运行结论来自独立验证报告。
