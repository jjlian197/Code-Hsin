# 本地回复、听写与角色音色

v1.2.0便携版已提供本地后端入口，大模型与独立Python环境由用户部署。基础陪伴、模型动作和固定回应无需部署大模型。

1. 解压完整便携包，在首次引导导入PMX，保留贴图目录。默认侧躺FBX及两形态过渡已内置；默认过渡只适用校验匹配的原模型，其他PMX需重新校准。
2. 已有Ollama用户直接复用模型。在设置选择Ollama，地址通常为`http://127.0.0.1:11434`，填入自己的模型名称。项目实测使用`huihui_ai/qwen3.5-abliterated:4b`，这是Huihui修改版，不是官方Qwen基线；关闭思考、上下文4096。界面不会代替你下载模型。
3. 麦克风选择Qwen ASR，在统一设置选择安装了qwen-asr/PyTorch的独立Python程序和官方Qwen3-ASR-0.6B本地目录，设备填`cpu`、`4080`、`8gb`或GPU UUID。热词每行一个，沿用心/心月狐/御者等词表。保存后主动开麦；模型缺失明确提示，不隐式下载。Whisper已移除。
4. 新文字使用心的音色，导入完整GPT-SoVITS音色配置；环境、权重及参考音频按[部署说明](GPT_SOVITS_SETUP.md)准备。Qwen TTS为可选实验方案，独立环境及中日模型也需用户准备。固定预存回应不依赖这些推理环境。
5. 使用Ollama后端时，可选本地翻译。关闭Edge备用与云识别可避免对应云调用；尚未完成系统断网验收，不能仅凭设置宣称整套已经完全离线。

默认600秒无活动后释放应用拥有的ASR/GPT-SoVITS，等生成、识别、合成、预热、实际播放及待播队列结束；高级设置可设0关闭。下一次请求重新加载，冷启动有明显等待。

4080S实测全GPU组合净显存峰值约9.9GiB；ASR用CPU后约7.9GiB，RAM峰值约10.5GiB，热听写从约0.7秒增加到2.4–2.7秒。8GB显卡仍需进一步轮换/分配与真机验收。合成录音的链路测试不能替代真人麦克风和内容质量验收；4B实验聊天尚未开放工具执行，日语回答仍可能不符合预期。

升级时保留自己的`config.local.yaml`、音色配置及模型目录，不覆盖成别人的开发机路径，不把密钥文件发给别人。程序与资源必须使用同一版本；保留整个`_internal`。
