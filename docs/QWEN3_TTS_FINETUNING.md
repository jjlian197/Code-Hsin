# Qwen3-TTS 单说话人微调尝试

2026-10-05，按用户要求使用 RTX 4080 SUPER。通过显卡 UUID 固定训练和本次对照设备，不依赖 CUDA 序号；8GB 5060 Laptop 不承担训练。

基座为本机 Qwen3-TTS-12Hz-0.6B-Base。分别建立中文 `hsin_zh`、日文 `hsin_ja` 单说话人检查点，不混合两种配音原声。现有 GPT/SoVITS 权重、源录音及应用配置只读使用。

| 数据 | 中文 | 日文 |
| --- | --- | --- |
| 完整日常语音清单 | hsin_zh.all.list | hsin_ja.calm.all.list |
| 条数 | 36 | 36 |
| 总时长 | 933.95秒 | 1255.57秒 |
| 最长录音 | 70.25秒 | 92.79秒 |
| 训练/验证 | 34/2 | 34/2 |

保留此前受GPT-SoVITS长度限制排除的长录音，完整配对文本与音频，不截断。沿用已有非战斗筛选，不加入战斗喊叫。确定性划分2条验证数据，参考音频不进入验证集；参考原声使用既有音色配置，转换24kHz副本以满足官方Dataset要求。源数据已做过格式/信号检查，但没有逐条人工听审，不能宣称全部逐字吻合。

基于[官方单说话人流程](https://github.com/QwenLM/Qwen3-TTS/tree/main/finetuning)，官方脚本副本和SHA256记录保存在本机目录。适配Windows PyTorch SDPA、0.6B文字投影、显卡绑定、UTF-8、梯度检查点和验证记录。训练目标沿用主音频编码损失加0.3倍子编码预测损失；冻结说话人编码器，训练生成网络，不使用LoRA。

首次采用3轮、学习率2e-6、batch 1、梯度累积4、BF16；每轮保存完整可离线加载的检查点。不把GPT-SoVITS的20轮直接照搬到新模型。

两种语言训练均正常结束。验证损失下降只能说明训练目标有所改善；验证集每种语言仅2条，不能据此判断音色提升、准确率或泛化水平。后续使用未参与训练的新台词，对照基础模型的原声克隆与微调音色，用户试听后再决定增加轮次、调整学习率或接入应用。

本机产物位于 `.runtime/qwen3-tts-training/`：数据清单、音频编码、源脚本摘要、各轮检查点和训练报告均被现有忽略规则排除。`comparison/` 保存对照WAV与报告。没有公开上传或切换桌面精灵音色。

已完成4080S上4组同台词对照，共8条WAV：中文短句/专名、日文短句/数字。基础版使用原声克隆，微调版使用训练后的固定说话人；所有输出非空且信号有限。微调版整句合成7.67–11.99秒，音频长度3.44–5.60秒；基础版12.17–14.08秒、音频长度4.96–6.48秒。两种模式语速和输出长度不同，不能把耗时差直接归因于训练加速；是否漏读、音色是否更像仍待用户试听。检查点导出使用原始官方JSON结构，修复说话人配置序列化的加载兼容问题，已实际离线重新加载中日模型。
