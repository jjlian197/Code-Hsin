# 爱弥斯胸部改骨与补偿

适用本项目导入的爱弥斯1.05 PMX。原版SHA-256为`79b622d0a87ab61516d2c3008d241d9145daa905acbcbd29d070c68cc55fa437`，本轮改骨副本为`8b7294f38ace5dfae8ba65b400d4feb13897a1d15f828e285189fc56ef6f7854`。其他模型不会自动应用此修改；外部aemeath-spirit项目及其GLB运行时未修改。

## 模型与运行时

爱弥斯不是心的果冻胸结构。它使用六个绑定胸骨的动态刚体、一个胸部锚点和八个关节，没有心的十根ZSpring辅助骨。

- 将左胸上2（172）的亲骨骼从170改为左胸上（171），右胸上2（177）从170改为右胸上（176），与已有刚体关节链一致。
- 胸部十根骨171–180标记物理后；原世界位置、蒙皮权重、表情、衣发骨骼及其他模型数据不改动。
- 六个胸部动态刚体使用位置跟随骨骼、受限旋转模式，保留原刚体尺寸、质量与碰撞组。八个胸部关节平移限制为零，旋转限制改为对称范围，回弹系数8；上部/下部为±0.12/±0.12/±0.08弧度，第二段仅X轴±0.12，交叉辅助关节仅X轴±0.2。

日常播放器对上述原版和改骨副本都自动应用这套适配。文件副本仅包含改骨；补偿由本项目播放器在运行时提供，外部PMX软件打开副本不会自动获得这套补偿。原模型与当前角色设置保留。

本机独立副本和贴图位于`.runtime/aemeath-chest/model/爱弥斯_胸骨改绑_物理后.pmx`，不纳入Git或发行包。重建命令：

```powershell
node tools/patch_aemeath_chest.mjs "原版爱弥斯1.05.pmx" "新目录/爱弥斯_胸骨改绑_物理后.pmx"
```

工具要求匹配原版哈希且输出PMX不存在，输出改骨记录并复制引用的贴图。

## 检查与对照预览

使用用户提供的`Treadmill Running.fbx`按爱弥斯骨长重定向，半速播放约15.73秒。v1.4.0已将该动作接入爱弥斯日常菜单，并开放点头、挥手、V手势、比心和X手势；躺下保持禁用。旧版角色包的基础动作清单会按已验证模型哈希自动升级。

四组原生Qt/WebGL对照通过：原版原生、仅改骨、原版自动改骨加补偿、改骨副本加补偿。每组470帧、47次采样，骨骼均为有限值、贴图错误0；补偿组胸骨局部位置漂移为0且存在实际旋转变化，关闭物理后胸骨保持稳定。角色包加载检查确认默认六刚体补偿、12种表情和五元音口型可用。原物理后求解与心的双形态半速关键帧检查仍通过。

这些检查证明默认适配生效和基本稳定性，观感仍需用户比较。爱弥斯手势按实际指尖末端骨和上胸基准校准；跑步掌面、衣物碰撞与其他角色复杂手势校准继续单独处理。
