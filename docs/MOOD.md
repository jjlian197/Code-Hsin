# 心情与好感度

右键或托盘 → **心情与好感度 → 查看陪伴状态…**，查看当前心情、好感度、关系阶段、自动表情解锁项及今日增长。面板独立于角色，穿透或隐藏心时仍可操作，关闭面板仍会记录互动。

## 互动规则

初始好感度 30，范围 0–100，四个阶段：

| 好感度 | 关系 | 自动回应与表情 |
| --- | --- | --- |
| 0–29 | 相识 | 基础回应；从容、安心、惊讶、闲置时想念/困倦 |
| 30–59 | 相伴 | 对话完成时开心 |
| 60–79 | 信赖 | 摸头害羞，成功对话欢欣；解锁脸红、笑眯眯及更亲近的中日触摸回应 |
| 80–100 | 心意相通 | 触摸手部可进入亲近情绪，解锁自动爱心眼及另一组中日回应 |

轻触头部/身体/手/尾巴增加 1 点，共用 15 秒增长间隔；成功完整回复增加 2 点，间隔 60 秒；番茄钟完成专注增加 3 点，间隔 60 秒。每天最多增加 20 点，到 100 后不继续增加。失败、停止和旧回复不计分，休息完成和取消专注不计分。冷却与每日额度保存到本地，重启不绕过冷却。按本机自然日恢复每日额度，时钟倒退不额外重置。

轻触仍可触发表情和回应，即使当前没有增加好感度。关闭触摸反应时不记录触摸奖励；聊天和专注仍正常记录。正在回复、合成/排队朗读或已有音频播放时，触摸不替换聊天气泡、不取消语音；情绪状态仍更新。

触摸一般安心，摸尾巴短暂惊讶；根据关系阶段，摸头可害羞，摸手可亲近。成功对话使心开心/欢欣，完成专注使心安心。互动情绪约 45 秒后回到从容，惊讶约 12 秒。无互动 30 分钟后想念、60 分钟后困倦；正在对话、朗读或专注时不判定为闲置。离开电脑、隐藏或退出不会扣好感度，重启从从容状态开始。当前状态由这些桌面事件决定，尚未接入对聊天内容的情感分析或修改 Hermes/DeepSeek 语气。

## 自动表情与数据

“让心情自然影响表情”只控制自动表情，不暂停好感度记录或锁住手动表情。选择“平常”允许自动情绪柔和叠加；其他手动表情、手动动作、拖动、触摸和 VMD 表情优先。两个形态都使用自身原生 morph，口型、眨眼、呼吸与物理继续运行。自动解锁不会限制手动菜单中的 12 个表情，指尖比心与双手交叉仍待细化。

好感度、开关、增长日期和冷却保存于 `.runtime/mood.json`，不保存聊天内容。临时情绪和最近互动仅保存在本次进程。原子写入失败不修改已保存的好感度，面板显示错误；坏文件在下一次成功写入前保留为 `mood-invalid-*.json`，无法备份时不覆盖原文件。

## 本地接口与验证

HTTP `POST /api/mood` 请求体为下方 data 对象，或使用 WebSocket：

```json
{"type":"mood","data":{"action":"status"}}
{"type":"mood","data":{"action":"open"}}
{"type":"mood","data":{"action":"configure","auto_expression":false}}
```

响应为 `mood_status`，含 mood、label、expression、affection、tier、tier_index、next_threshold、unlocked_expressions、auto_expression、earned_today、daily_limit、last_event、error。`get_status.data.mood` 提供同样的快照；变化通过 WebSocket 广播 `mood_status`。接口不提供直接加分或更改好感度的命令。

Python 测试覆盖冷却、每日额度、跨日/时钟倒退、重启、坏文件备份与保存失败、成功对话和专注的计分、穿透/隐藏面板及语音优先；Node 测试验证真实双形态 morph、手动优先及眨眼兼容。`python -m tools.verify_mood` 在原生 Qt/WebGL 中模拟临时进度，验证真实点击、双形态脸红/爱心眼、手动优先、关闭释放、面板与恢复保存；不联网、不录音、不修改用户的实际进度。
