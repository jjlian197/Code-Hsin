# 麦克风识别

v1.2.0移除Whisper识别入口、工作进程和依赖。默认Qwen ASR本地听写，亦可选择智谱云识别；旧Whisper选择启动时迁移为Qwen，需要补齐Qwen环境与模型。旧云识别回退配置不再调用Whisper。

右键/托盘或聊天窗口主动开启麦克风，说完停顿自动识别并发送当前聊天后端。每次启动默认关麦；回复与朗读期间暂停收音，取消和切换丢弃旧识别结果。识别语言与回复语言分别选择。

统一设置中为Qwen选择已安装qwen-asr/PyTorch的独立Python程序、官方Qwen3-ASR-0.6B本地目录及设备（cpu、4080、8gb或GPU UUID）。模型不随包提供，缺失时提示，不隐式下载。音频只在本地内存中用于短句识别，默认闲置10分钟释放自己管理的模型，下次自动重载。具体配置见[本地部署](LOCAL_SETUP.md)。

智谱需要自己的Key，并上传当前短句；失败明确报错。兼容旧“自动”配置时，中文且已配置智谱Key选择智谱，否则选择Qwen；界面可以明确选择本地或云端。

默认热词：心、心月狐、御者、鸣潮、鳴潮、Hsin。麦克风设置每行一词，清空关闭提示，最多100项、每项40字符。Qwen使用context、智谱使用热词列表，不强制替换听写文字。说完停顿默认700ms，底噪门限默认250，可在设置调整。

真人收音、专名与混合语言仍需用户验收。4080S合成录音测试通过功能链路，日语“二文→二分”仍可能出错；CPU听写较慢且RAM更高。此版不承诺8GB同时常驻或数小时稳定性。
