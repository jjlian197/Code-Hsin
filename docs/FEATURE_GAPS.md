# 与 aemeath-spirit 的功能差距

核对日期：2026-10-03。对照本机 `D:/Workspace/aemeath-spirit` 的菜单、渲染器、脑模块、对话链路和生活助手代码；本清单记录当前差距，不代表所有旧实现都适合原样迁移。

## 已完成的共同能力

透明窗口、托盘、拖动、置顶、穿透及恢复、大小调整、气泡、HTTP/WebSocket 控制、眼神跟随、眨眼、呼吸、触摸反应、基础表情和动作、实际音频口型、中日 GPT-SoVITS、文字聊天、DeepSeek 直连均已接入。心另外支持直接 PMX、双形态、原生刚体物理和默认本地 Hermes。

Hermes 与 DeepSeek 已通过实际中日连续对话；Hermes 的聊天→合成→播放→口型已通过原生桌面验证。OpenClaw 按用户要求只保留接口和设置入口，停止联调，不列为已验证可用。

## 尚未实现或只有部分能力

语音识别 / 麦克风对话已按最新要求实现：录音、VAD、智谱 / 本地 Whisper、中日识别、设备设置与对话链路，详见 [STT](STT.md)。

## 按用户要求暂缓

- **OpenClaw 服务联调及启动管理**：按“openclaw 先不去管它，只留下接口”保留接口，不自动启动 OpenClaw 或 WSL。
- **其他生活助手功能**：本次只实装番茄钟；便签、待办、软件入口、文件分析和侧边快捷按钮暂缓。

## 建议顺序

对话姿态、扩展表情、随机待机小动作、分句朗读和番茄钟已接入。指尖比心与双手交叉优先列为动作细化项；长回复朗读范围、500 字限制和语音听感仍待改善。其他生活助手功能暂缓。macOS 与 visionOS 版本按对应 Aemeath spirit 体验继续列入平台计划。
