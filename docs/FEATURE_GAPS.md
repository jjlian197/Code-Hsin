# 与 aemeath-spirit 的功能差距

核对日期：2026-10-02。对照本机 `D:/Workspace/aemeath-spirit` 的菜单、渲染器、脑模块、对话链路和生活助手代码；本清单记录当前差距，不代表所有旧实现都适合原样迁移。

## 已完成的共同能力

透明窗口、托盘、拖动、置顶、穿透及恢复、大小调整、气泡、HTTP/WebSocket 控制、眼神跟随、眨眼、呼吸、触摸反应、基础表情和动作、实际音频口型、中日 GPT-SoVITS、文字聊天、DeepSeek 直连均已接入。心另外支持直接 PMX、双形态、原生刚体物理和默认本地 Hermes。

Hermes 与 DeepSeek 已通过实际中日连续对话；Hermes 的聊天→合成→播放→口型已通过原生桌面验证。OpenClaw 按用户要求只保留接口和设置入口，停止联调，不列为已验证可用。

## 尚未实现或只有部分能力

## 按用户要求暂缓

- **语音识别 / 麦克风对话**：旧项目已有录音、VAD、ASR 和识别语言设置；当前按“可以考虑跳过自动识别环节”未接入。
- **OpenClaw 服务联调及启动管理**：按“openclaw 先不去管它，只留下接口”保留接口，不自动启动 OpenClaw 或 WSL。

## 建议顺序

先适配思考与说话姿态、扩展表情和随机待机小动作；再增加分句朗读以减少等待。生活助手可随后独立迁移，文件分析需要针对 Hermes 的附件能力验证。情绪与好感度的规则应结合心的人设设计。
