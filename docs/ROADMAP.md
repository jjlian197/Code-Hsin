# 心桌面精灵后续计划

更新：2026-10-02。以下是后续工作顺序与验收目标，尚未实现的项目不会在当前版本中展示为可用功能。

## 当前版本

- 独立透明窗口、托盘、拖动、穿透恢复、气泡、HTTP/WebSocket 控制。
- 可双击的启动、重启与停止入口，自动查找可用 Python，启动预检与失败日志；支持从项目目录外启动。
- 直接 PMX 双形态、原生头发与衣摆物理、眨眼、呼吸、转头、视线跟随、分部位触摸反应。
- 七种基础表情，待机、点头和挥手；本地 VMD 接口。动作首尾保持下垂手臂，挥手掌心朝向正面镜头。
- 心的中日 GPT-SoVITS 各完成 GPT/SoVITS 20 轮训练，双语言实际合成、触摸发声与 PCM 口型已验证。
- 默认连接已有 Hermes Hsin Agent；DeepSeek 直连支持流式文字、独立上下文与语音回复。
- 自动翻译直接朗读文本、GPT-SoVITS/Edge 引擎选择、合成失败备用音色与独立缓存。配置可由语音菜单或控制接口切换。
- OpenClaw 按用户要求只保留接口，不启动服务、不继续联调；麦克风识别暂缓。

## 第一阶段：对话与陪伴动作

1. **思考和说话姿态**：等待回复时进入思考姿态，开始朗读时使用轻微说话手势，停止、出错和切换后端后回到待机；自然眨眼和物理继续运行。
2. **扩展表情与菜单**：检查两个 PMX 的原生 morph，适配脸红、放松等可用表情，补齐右键表情选择；不能依靠不存在的贴图假装已经实现星星眼或爱心眼。
3. **随机待机小动作**：加入低频环顾、伸懒腰等行为；触摸、主动动作、拖动、聊天和语音期间暂停自动动作，结束后自然恢复。
4. **更多手势**：逐个适配比心、V 手势与交叉手臂，再评估蹲下。验收包括双形态掌面朝向、手指姿态、衣服碰撞、动作中断和结束恢复。

## 第二阶段：缩短对话等待

1. **分句流式朗读**：收到完整短句即可合成，文字接收与播放并行；保留句子顺序，取消后丢弃未播放语音，不重复朗读。中日切换、缓存和备用音色要继续正确隔离。
2. **回复长度与朗读范围**：为长回复提供可见的朗读范围选择，改进当前最多朗读 500 字的限制，保留聊天全文。
3. **语音体验检查**：对不同语速、长短句、专名和混合语言做听感检查；客观音频检查不能替代听感。必要时调整参考原声与推理参数，避免重复训练覆盖现有权重。

## 第三阶段：生活助手

1. **便签、待办、常用软件**：迁移参考项目面板，数据独立保存在心的目录，读写失败保留原数据。
2. **番茄钟**：支持专注/休息、暂停/继续、头顶倒计时与到时提醒；隐藏角色、关闭面板不改变计时语义。
3. **文件分析**：首先确认 Hermes 当前版本的附件协议与支持格式，再接入拖放和独立分析会话；明确发送时机，显示上传和分析错误。当前不能把本地路径当作已经上传的附件。
4. **侧边快捷按钮**：助手功能稳定后再加入文件、便签、软件、专注和语音入口，保持穿透模式下可操作。

## 第四阶段：长期状态与发布

1. **情绪与好感度**：结合心的人设设计互动规则、闲置状态与解锁行为，避免直接照搬爱弥斯的称呼和性格。
2. **外观设置**：大头模式、背景菜单和动作文件选择器；VMD 保持直接适配，Mixamo 需另行骨骼重定向。
3. **独立 EXE**：增加打包脚本和启动诊断，在未安装开发环境的新 Windows 机器上验证窗口、模型资源、Edge、Hermes 连接及退出清理。
4. **渲染与接口完善**：评估 SDEF 精确蒙皮、复杂 VMD/IK、口型广播和长期运行的资源释放。

## 暂缓项

麦克风 / VAD / ASR、OpenClaw 实际服务联调及自动启动，等待用户后续明确要求恢复。完整差距见 [功能差距清单](FEATURE_GAPS.md)。

## 验证方式

```powershell
python -m unittest discover -s tests -p 'test_*.py'
node tests/test_motion_clips.mjs
node --loader ./tools/node_three_loader.mjs tests/test_behavior.mjs
python -m tools.verify_motion_regressions
python -m tools.verify_voice_auxiliary
```

Python 单元测试使用临时状态和模拟网络，不需要分发训练数据；模型相关 Node/原生检查需要本机自行配置的 PMX。真实语音辅助检查会调用 DeepSeek 和 Edge，并读取本机训练权重，验证报告只保存在未提交的 `.runtime/`。
