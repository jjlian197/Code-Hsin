# 心桌面精灵后续计划

更新：2026-10-03。以下是后续工作顺序与验收目标，尚未实现的项目不会在当前版本中展示为可用功能。

## 当前版本

- 独立透明窗口、托盘、拖动、穿透恢复、气泡、HTTP/WebSocket 控制。
- 可双击的启动、重启与停止入口，自动查找可用 Python，启动预检与失败日志；支持从项目目录外启动。
- 直接 PMX 双形态、原生头发与衣摆物理、眨眼、呼吸、转头、视线跟随、分部位触摸反应。
- 12 种原生表情与选择菜单；待机、点头、挥手、V 手势和本地 VMD 接口；双手比心与胸前 X 手势已按 Aemeath 更新方案校准到两个 PMX。动作首尾保持下垂手臂并恢复手指，挥手与 X 手势掌心朝向正面镜头。
- 自动思考、说话和倾听姿态；低频随机环顾与轻微伸展。右键“陪伴动作”可独立关闭，手动动作、触摸、拖动和对话优先。
- 心的中日 GPT-SoVITS 各完成 GPT/SoVITS 20 轮训练，双语言实际合成、触摸发声与 PCM 口型已验证。
- 默认连接已有 Hermes Hsin Agent；DeepSeek 直连支持流式文字、独立上下文与语音回复。
- 自动翻译直接朗读文本、GPT-SoVITS/Edge 引擎选择、合成失败备用音色与独立缓存。配置可由语音菜单或控制接口切换。
- 对话分句朗读：完整短句到达即合成，实际播放与接收文字并行，最多预合成两句；停止、失败和切换设置取消队列，最终回复补尾句且不重复。中日真实音色、PCM 口型和顺序已验证。
- 麦克风录音、VAD 断句、中日 STT、回复期间暂停收音及取消旧识别；智谱与本地 Whisper 共享热词“心、心月狐、御者、鸣潮、鳴潮、Hsin”，支持设置编辑。中日离线识别已验证，真实麦克风与智谱联网验收待完成。
- OpenClaw 按用户要求只保留接口，不启动服务、不继续联调。
- 番茄钟：独立面板、专注/短休息/长休息、暂停/继续、头顶倒计时和到时气泡/托盘/可选提示音；设置保存在本项目，隐藏角色与关闭面板继续计时。
- 情绪与好感度：触摸、成功对话和完成专注驱动，四阶段解锁自动表情与中日回应；持久化、冷却与每日增长上限已接入，闲置改变情绪但不扣好感度。菜单可查看与关闭自动情绪表情。
- 站立与侧躺双形态过渡：CMU 躺下/独立起身重定向到 PMX，匹配原待机与撑头侧躺；固定地面、稳定比例、宽窗口、连续切换与动作排队已接入。修复启动颈部扭曲与起身后双臂平举；侧躺衣发加入骨骼布料动态模拟，支持重力、阻尼、骨链/邻接约束及身体/地面碰撞，开关与重置沿用原菜单。
- 修复侧躺后点击待机仍横躺：退出时还原完整骨骼与动画缓存，双形态实际菜单、身体世界位置和站立截图已纳入回归检查。

**已完成：分部位触摸与大头模式**。头脸默认双手比心、胸部双手比叉、手部 V 手势、其他身体挥手、尾巴惊讶回头；全身和正面/左右斜侧近景共用真实网格命中。右键/托盘“显示模式”切换并记住视角，躺稳后支持正面/左右斜侧的上半身近景，躺下/起身过程暂用全身、站稳恢复对应视角。触摸关闭、空白、冷却期和拖动均不触发，侧躺及外部动作不会被强制中断。后续按观感细化头发/腿部专属动作及手势节奏，仍需解决复杂袖摆碰撞。

大头模式已加宽为默认 1000×600，保留近景大小和斜侧方向，减少两侧手臂裁切；切回全身恢复原尺寸，大小菜单与侧躺恢复共用尺寸基准，画布不超出可用屏幕；窄屏时相应放宽取景。

2. **已完成：12 种原生表情与菜单**。两个 PMX 都有脸红、放松、笑眯眯、星星眼和爱心眼 morph，已适配；没有原生吐舌，所以不提供该项。

## 第二阶段：缩短对话等待

1. **已完成：分句流式朗读**。收到完整短句即合成，接收文字、合成和播放并行；前句结束后才播后句，最多预合成两句。中日首句均已验证在回复完成前播放；停止/切换与迟到结果隔离、尾句补全、缓存及备用音色保持正确。首次本地模型冷启动仍需等待，未把分句等同于消除模型加载时间。
2. **回复长度与朗读范围**：为长回复提供可见的朗读范围选择，改进当前最多朗读 500 字的限制，保留聊天全文。
3. **语音体验检查**：对不同语速、长短句、专名和混合语言做听感检查；客观音频检查不能替代听感。必要时调整参考原声与推理参数，避免重复训练覆盖现有权重。

## 第三阶段：生活助手（本次只实装番茄钟）

1. **已接入：番茄钟**。右键/托盘“番茄钟…”打开独立面板；默认 25/5/15 分钟，每四轮专注长休息，时长可调。支持暂停/继续、重置本轮、头顶倒计时与气泡/托盘/可选提示音。到时等待手动开始下一阶段；隐藏角色、关闭面板继续计时，退出程序结束本次计时，重启保留设置。详情见 [番茄钟](POMODORO.md)。
2. **按用户要求暂缓：便签、待办、常用软件、文件分析、侧边快捷按钮**。当前不迁移其他生活助手功能；以后恢复文件分析时先验证 Hermes 附件协议，不能把本地路径当作已上传附件。

1. **已完成基础版：情绪与好感度**。结合心对御者温柔从容的人设，提供从容、安心、开心、欢欣、害羞、亲近、惊讶、想念和困倦；好感度 0–100、相识/相伴/信赖/心意相通四阶段，触摸与成功对话/专注增长，有冷却与每日上限，不离线扣分。自动情绪柔和叠加于平常表情，手动表情、动作、触摸和 VMD 优先；状态本地保存，重启保留好感与设置。详情见 [陪伴状态](MOOD.md)。后续再评估更多人设事件、规则调节和聊天语气联动。

4. **渲染与接口完善**：评估 SDEF 精确蒙皮、复杂 VMD/IK、口型广播和长期运行的资源释放。

## 后续平台：macOS 与 visionOS

**后续必须安排心的 macOS 和 visionOS 版本，分别对齐 Aemeath spirit 对应平台的体验与功能。** 当前实现和验证只覆盖 Windows；以下是后续计划。

1. **先核对参考版本**：整理 Aemeath spirit 在 macOS、visionOS 的功能与平台差异，建立逐项对应清单；复用心的人设、模型资源、热词、语音配置和控制协议，避免照搬 Windows 的窗口与权限代码。
2. **macOS 版**：适配透明置顶窗口、菜单栏、拖动与穿透、启动/退出、麦克风权限和设备切换；验证 PMX/物理、口型、中日 STT/TTS、Hermes 与 DeepSeek。分别评估 Apple Silicon 与 Intel 的语音推理环境、资源路径及打包方式。
3. **visionOS 版**：参考 Aemeath spirit 对应实现，评估空间角色呈现、模型/物理资源适配、视线与手势互动、空间气泡和音频；决定设备端识别与局域网语音/Agent 服务的分工，保留独立配置。需真机验证输入权限、性能、交互和发布方式。
4. **平台验收**：各平台独立启动和清理，中文/日语对话完整往返，录音开关及隐私提示可见；用对应 Aemeath spirit 清单记录完成、差异与未实现项，不能仅凭 Windows 测试宣布其他平台可用。
