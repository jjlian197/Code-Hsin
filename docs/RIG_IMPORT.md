# 骨架整合器：校正与基础动作接入

更新：2026-10-06。独立校正工具与桌面精灵已共用骨架匹配规则，运行时接入待机、点头和视线跟随；本地角色包加载与爱弥斯表情/口型通道已接入，通用复杂动作适配仍待开发。

## 已实现范围

- Hsin Standard Rig v1：63 个语义槽位，其中 16 个必需人体骨；控制根、中心、Groove 与骨盆独立定义，包含可选躯干、肩、眼睛、脚趾、IK 和手指。
- 复用项目 MMDParser，读取原名/英文名、父子层级、位置、IK、Grant、固定轴、局部轴与刚体关联；不更改 PMX。
- 名称匹配支持 NFKC、MMD 日文、多种英文别名及常用中文名。结合父子链和左右位置检查，跳过中间辅助骨；重复候选、左右冲突、IK 角色冲突和辅助骨疑点不自动接受。
- 未知名称的人体关节可依据已接受的父骨和空间关系提供最近候选，始终待人工确认。缺少可选躯干骨不会拿头部、肩膀或衣物骨补齐。
- 人工指定索引或禁用语义槽位；覆盖文件绑定 PMX SHA-256，并拒绝重复索引或未知语义。
- 自包含 HTML 骨架预览，支持旋转、缩放、语义过滤、辅助骨显示、选骨定位、人工校正及修正 JSON 导出/导入；直接双击打开，无需联网。
- 运行时按语义访问原始骨骼，保留名称、索引、IK/Grant。标准骨名继续沿用原基础动作轨道；自定义映射使用实际骨骼索引。复杂手势只开放给已校准的 Hsin 双形态。

## 使用

在项目根目录运行，使用本机已有 Node.js，不需要安装额外 npm 包：

```powershell
node tools/analyze_pmx_rig.mjs "D:\模型目录\角色.pmx"
# 可指定输出位置；对已存在的输出，明确加 --force 才重建。
node tools/analyze_pmx_rig.mjs "D:\模型目录\角色.pmx" --out ".runtime/rig-import/my-character"
```

默认输出至 `.runtime/rig-import/<PMX哈希前12位>/`：

| 文件 | 内容 |
| --- | --- |
| `rig_map.json` | 格式版本、模型文件名/名称/哈希、语义映射、状态、候选、分数、问题与映射能力摘要 |
| `report.json` | 上述内容加完整骨架快照，供检查和预览使用 |
| `preview.html` | 内嵌骨架与报告的独立页面，不包含 PMX 网格或贴图 |

索引对应当前 PMX 骨骼数组；改模后哈希变化，需要重新分析。`matched` 为自动接受，`manual` 为人工指定，`review` 为待确认，`missing` 为没有可靠候选，`disabled` 为人工禁用。只有 `matched/manual` 包含已选择的 `index`；待确认项的候选不能作为运行时映射使用。分数表示规则可信度，不是统计概率。

坐标来自 `parsePmx(..., true)` 的右手系、Y 向上转换；绑定姿势中解剖左侧通常为 +X，按模型中心的相对位置判断左右。偏转、镜像或特殊绑定姿势可能进入待确认，不能自动推断所有模型朝向。

## 人工修正

打开 `preview.html`，点击表格中的语义骨，在“指定骨骼”中选择实际骨骼，再点“应用校正”。也可选择“禁用此语义”或“恢复自动匹配”。页面会重新计算映射与冲突；报错时保留上一次有效修正。

点“导出修正 JSON”保存文件；“导入修正 JSON”可恢复同一模型的修正。页面修改不会自动写入角色配置，关闭前需导出。导出的格式如下，也可手工编写：

```json
{
  "modelSha256": "填写报告中的完整sha256",
  "bones": {
    "head": 42,
    "upper_chest": null
  }
}
```

```powershell
node tools/analyze_pmx_rig.mjs "D:\模型目录\角色.pmx" --overrides ".runtime/rig-import/overrides.json" --force
```

未指定的槽位继续自动匹配，`null` 禁用对应项；人工索引优先预留。人工指定仍检查左右、父子链、辅助骨与 IK 角色，问题保留在报告中，预览选中该语义后显示警告。输出不能覆盖 PMX 或人工修正输入文件。

## 运行时接入

开发版加载 PMX 时默认自动匹配。需要使用人工修正时，先通过上述 `--overrides` 命令生成 `rig_map.json`，再在项目配置的 `sprite.animation.rig_maps` 中指定模型与映射文件；路径相对项目根目录：

```yaml
sprite:
  animation:
    rig_maps:
      "模型目录/角色.pmx": ".runtime/rig-import/my-character/rig_map.json"
```

键必须对应实际加载的 PMX。运行时校验格式版本、模型 SHA-256、骨骼数量、索引、原名与重复映射；已选骨存在结构冲突时拒绝加载，需先修正报告。改模后重新分析。本轮未改动用户的日常配置。

基础动作和行为通过统一语义入口访问躯干、头颈、眼睛、手臂与手指；缺失可选骨跳过相应操作。未校准的新模型仅生成待机与可用时的点头，即使使用标准骨名也不开放复杂手势，触摸不会调用未提供的动作。原 Hsin 双形态保留现有复杂手势路径；Morph、触摸区域分类、过渡与物理校准还包含角色专用规则，尚未通用化。
