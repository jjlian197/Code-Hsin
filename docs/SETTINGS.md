# 统一设置与首次启动

首次正常启动时，心会打开引导，提供“连接已有 Hermes”“使用 DeepSeek 直连”和“先使用基础陪伴”。已有连接、密钥、音色和识别配置会读取并保留；基础陪伴可关闭 AI 对话与自动语音，不需要填写 Key。引导不会自动打开麦克风。

按“下一步”依次检查连接、语音、麦克风与模型资源，在资源页完成保存；外观与内部端口留在之后的普通设置。选择“稍后设置”或关闭窗口不会保存，下一次启动仍显示引导；成功保存后不再自动显示。验证用的离屏/限时启动不显示引导。

以后从 **右键菜单或托盘 → 设置…** 打开同一套表单；原“连接设置…”和“麦克风设置…”快捷入口也进入对应页面。

- **连接**：开启/关闭 AI 对话，选择 Hermes、DeepSeek 或预留 OpenClaw，填写 Agent 名称及 DeepSeek Key；设置回复长度、自动朗读范围与数量，也可在聊天窗口快速修改。
- **语音**：中文/日本語、心的本地音色/联网通用音色、音量、翻译与备用音色。
- **麦克风**：设备、语言、识别方式、智谱 Key、本地模型目录与热词。保存不自动开麦；需要在菜单或聊天窗口主动开启。
- **资源**：选择双形态 PMX、侧躺 FBX、对应的过渡校准文件和中日音色配置。PMX 的贴图保持原目录结构；音色配置引用的推理环境、权重及参考原声需存在。
- **外观**：置顶与不透明度；视角、尺寸、背景、物理和眼神跟随仍可用菜单快速切换。
- **高级**：本地地址、数据目录、会话凭据、模型名、内部端口、停顿与底噪门限。

“检查本地配置”只检查文件、组件与凭据是否配置，不发起云端请求、合成或录音，也不把登记文件存在当作已经连通服务。缺少资源仍可保存，之后继续补齐。启动器不会因为缺少 PMX 提前阻止进入引导。

连接、语言、音量、识别与外观保存后生效。模型/动作、音色资源配置及端口修改需要重启；保存后会提示。重启脚本通过当前运行实例登记的地址退出旧实例，再按新端口启动。端口占用仍需自行调整，尚未实现自动分配。

高级设置中的“本地听写与音色闲置释放”默认为600秒，0为关闭，保存后生效。聊天生成、识别、合成、预热及播放队列全部结束后才计时，释放应用自己启动的Qwen ASR和GPT-SoVITS进程，下次请求重新加载；已有缓存仍可播放，但不代表模型已经预热。该设置与角色形态的10分钟闲置回退分别计时。

v1.3.0 便携版设置写入 `Hsin/data/config.local.yaml`，安装版写入 `%LOCALAPPDATA%\Hsin/config.local.yaml`，源码版仍写当前配置文件旁的 `config.local.yaml`；合并保留其他本机配置；快捷语言/音色等运行状态仍由原有状态文件保存。支持自定义 `--config` 路径。密钥输入框隐藏字符，但当前保存仍是被 Git 忽略的本地明文文件；系统凭据库和托管云网关尚未接入。

验证：35 项设置/配置/聊天/桌面控制检查通过；原生窗口验证了缺模型进入引导、基础陪伴保存、不重复引导、普通设置重开/取消与页面布局。全过程使用隔离配置，不连接云服务、不录音。
