# 域名桥接实测

> 本文记录早期未鉴权入口测试，不是当前部署状态。后续已接入 Bearer 鉴权与 HTTPS 客户端；当前使用见 [PC 语音指南](MACOS_PC_VOICE.md) 和 [macOS 开发状态](MACOS_STATUS.md)。

2026-10-07，入口 `https://bridge.oieasklja.icu`。本次仅验证公开测试台词与合成录音，不启用麦克风、不上传私人录音或凭据，不修改网关、PC 服务或用户设置。

## 结果

- HTTPS `/health` 返回 `hsin-pc-voice`、协议 1、心与爱弥斯音色。5 次独立 HTTPS 连接均成功，耗时 0.53–1.00 秒；这不是长时间稳定性结论。
- Python urllib 默认 User-Agent 收到 Cloudflare 403；相同调用使用 `HsinBridge/1.0` 或 curl 标识成功。Python `http.client.HTTPSConnection` 默认请求也成功。这里只确认访问差异，尚未确定具体网关规则，不应以伪装浏览器代替网关配置。

| TTS | 请求至完整 WAV 返回 | 音频时长 | Mac 实际播放 |
| --- | --- | --- | --- |
| 心 / 中文 | 5.264 秒 | 7.000 秒 | PlayingState 与 110 个 PCM 缓冲 |
| 爱弥斯 / 中文 | 3.959 秒 | 5.080 秒 | PlayingState 与 80 个 PCM 缓冲 |
| 爱弥斯 / 日文 | 8.643 秒 | 5.380 秒 | PlayingState 与 85 个 PCM 缓冲 |

以上为本次固定新句的单次实测，包含网络与服务处理，不代表平均推理性能，也未区分冷启动状态。实际播放使用独立 Qt 音频播放器，未验证此次外网链路的 PMX 口型或安装版配置。

STT 使用上述爱弥斯中文合成音频转换为 16kHz 单声道 Int16 WAV。输入台词“父亲，这是外网桥接测试，爱弥斯已经准备好了。”，输出“父亲，这是万网桥接测试。爱弥斯已经准备好了。”，存在“外网 → 万网”误识别。请求总耗时 20.257 秒，服务报告 ASR 耗时 14.234 秒、设备 `cuda:0` / RTX 4080 SUPER。这是合成录音测试，不等于真人麦克风验收。

## 后续接入条件

本次 STT/TTS 请求均未携带鉴权凭据而成功执行，公网匿名推理可用；需要在网关或服务增加鉴权后再接日常客户端。当前 Mac RemoteVoice 仅允许回环 HTTP，尚未修改为公网 HTTPS 客户端。网关转发方式、Cloudflare 规则、推理超时与长时间断线恢复仍待确认。

原始证据与可重复运行的测试脚本保存在 `.runtime/public-bridge-validation/`，汇总为 `report.json`。

## 应用接入后的复验

同日已为 PC 桥接启用 Bearer 鉴权，匿名健康请求返回 401。Mac 新客户端支持标准证书验证的 HTTPS、应用 User-Agent、令牌与取消请求。私有配置已切换新域名；实际合成耗时 24.297 秒，STT 23.531 秒、完整正确识别“父亲，应用现在已经通过加密域名连接到电脑了。”，全程没有 SSH 进程或麦克风采集。

更新的 `dist/Hsin.app` 已签名检查、安装并实际启动，爱弥斯模型与音色恢复正常。新句经 HTTPS 实际进入 PlayingState，PCM 峰值 0.746，口型峰值 0.650；合成至播放结束观测 14.335 秒。旧包和私有配置保留备份。这些单次结果不证明长期稳定性。
