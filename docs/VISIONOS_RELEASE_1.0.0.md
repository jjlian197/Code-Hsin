# Hsin Spatial visionOS 1.0.0

版本：1.0.0 / Build 16。日期：2026-10-09。源码分支：`codex/visionos-port`；正式标签：`visionos-v1.0.0`。

## 本版内容

- 心双形态及爱弥斯；站立、侧躺、起身和跑步等动作与互动。
- 两角色中日触摸短句、独立开关、3 秒冷却及音色缓存；聊天／收音期间暂停，侧躺保持。
- 四阶段陪伴设置、角色情绪及好感度、提醒、显示与恢复设置。
- 实时骨骼衣发物理、身体体积碰撞、心胸部动态、全身补光与脚背朝前；移除爱弥斯导出器额外生成的腰背黑色矩形补片。
- 心使用 PC Hermes，爱弥斯使用既有 OpenClaw；HTTPS PC TTS／STT 与可选智谱 STT、持续语音和逐句口型播放。
